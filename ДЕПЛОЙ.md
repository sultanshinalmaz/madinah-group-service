# Деплой: GitHub → Vercel → Telegram Mini App

Порядок такой:

```
GitHub  →  Vercel  →  База (Postgres)  →  Хранилище файлов (Blob)
        →  Переменные окружения  →  Вебхук Telegram  →  Mini App
```

Проект уже к этому готов: есть `api/[...path].js` (функция Vercel), `vercel.json`,
`package.json` и `.env.example`. Ставить и собирать ничего не нужно — Vercel всё сделает сам.

---

## 1. GitHub

Репозиторий делайте **приватным**: там фото квартир, тексты и телефоны.
Секреты в него не попадут — `.env`, `bot/.env` и `bot/data/` перечислены в `.gitignore`.

```bash
git init
git add .
git commit -m "Madinah Group - Telegram Mini App"
git branch -M main
```

Создайте пустой приватный репозиторий на github.com (например `madinah-group`) и отправьте туда код:

```bash
git remote add origin https://github.com/ВАШ-ЛОГИН/madinah-group.git
git push -u origin main
```

Загрузится около 50 МБ — это фото и видео квартир. Для GitHub нормально.

---

## 2. Vercel

1. [vercel.com](https://vercel.com) → **Sign up with GitHub**.
2. **Add New… → Project** → выберите репозиторий `madinah-group` → **Import**.
3. Framework Preset — **Other**. Build Command и Output Directory не трогайте (они пустые).
4. **Deploy**. Через минуту проект развернётся и получит адрес вида
   **`https://madinah-group.vercel.app`** — это и есть адрес Mini App.

Пока не подключены база и хранилище файлов, приложение уже открывается, но данные сохранять
негде — поэтому сразу делайте шаги 3 и 4.

> Адрес можно поменять: Project → Settings → Domains. Если поменяете — обновите `APP_URL`
> (шаг 5) и разверните проект заново, вебхук Telegram переставится сам.

---

## 3. База данных (Postgres)

Здесь живут квартиры, услуги, тексты админки, заявки, сделки и отчёт.

1. В проекте на Vercel: вкладка **Storage** → **Create Database** → **Neon (Serverless Postgres)**
   → регион поближе к Медине (например Frankfurt) → **Create**.
   Подойдёт и Supabase, и любой другой Postgres — тогда просто впишите его строку подключения
   в переменную `DATABASE_URL` вручную.
2. **Connect Project** → ваш проект → Vercel сам добавит переменную **`DATABASE_URL`**.
3. Таблицу создавать не нужно: приложение при первом запросе само создаст таблицу `docs`
   и положит туда стартовый каталог из `assets/js/data.js`.

Бесплатного тарифа Neon хватает с запасом: данных здесь на пару мегабайт.

---

## 4. Хранилище файлов (Vercel Blob)

Здесь лежат фото и видео, которые загружает Абдуллах.

1. **Storage** → **Create** → **Blob** → название, например `madinah-media` → **Create**.
2. **Connect Project** → ваш проект → появится переменная **`BLOB_READ_WRITE_TOKEN`**.

Ссылки на файлы получаются постоянные, вида
`https://xxxxxxxx.public.blob.vercel-storage.com/media/apt-1234.webp`.

---

## 5. Переменные окружения

Project → **Settings → Environment Variables**. Отмечайте все три среды
(Production, Preview, Development).

| Переменная | Значение | Откуда |
|---|---|---|
| `BOT_TOKEN` | токен бота | @BotFather, шаг 7 |
| `ADMIN_TELEGRAM_ID` | `593048264` | Telegram ID Абдуллаха |
| `APP_URL` | `https://madinah-group.vercel.app/` — **со слэшем в конце** | адрес из шага 2 |
| `WEBHOOK_SECRET` | придумайте длинную строку из латинских букв и цифр | пароль вебхука |
| `DATABASE_URL` | появляется сама | шаг 3 |
| `BLOB_READ_WRITE_TOKEN` | появляется сама | шаг 4 |

Необязательные: `TRANSLATE_EMAIL` (лимит переводчика 50 000 знаков в день вместо 5 000),
`BLOB_BASE_URL` (адрес хранилища Blob — нужен, только если в данных остались старые ссылки `/media/…`).

**После добавления переменных обязательно разверните проект заново:**
Deployments → у последнего развёртывания «…» → **Redeploy**. Новые переменные подхватываются
только при новом развёртывании.

## 6. Вебхук Telegram

Постоянного процесса на Vercel нет, поэтому Telegram присылает сообщения сам — на адрес
`APP_URL` + `api/webhook`.

**Делать ничего не нужно:** приложение проверяет вебхук при первом же запросе после
развёртывания и, если адрес не тот, прописывает его само (вместе с `WEBHOOK_SECRET`).
Достаточно открыть в браузере `https://ваш-адрес.vercel.app/api/health`.

Проверить, что Telegram согласен:

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/getWebhookInfo"
```

Должен быть `"url":"https://ваш-адрес.vercel.app/api/webhook"` и пустой `last_error_message`.

Если нужно прописать вручную:

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://ваш-адрес.vercel.app/api/webhook&secret_token=<WEBHOOK_SECRET>&max_connections=1"
```

## 7. Бот в @BotFather

1. `/newbot` → имя **Madinah Group** → username вроде `MadinahGroupBot`.
   Токен → в переменную `BOT_TOKEN` (шаг 5) → Redeploy.
2. `/setmenubutton` → ваш бот → адрес = `APP_URL` → название кнопки **Каталог**.
   Это кнопка Mini App, её видят все.
3. `/newapp` (по желанию) → короткая ссылка `t.me/MadinahGroupBot/catalog` для канала
   @madinah_rent. Обложка готова: `deploy/cover-1280x720.png`.
4. `/setcommands` (по желанию):
   ```
   start - Открыть каталог
   help - Команды
   id - Мой Telegram ID
   ```

Telegram ID Абдуллаха уже известен — **593048264**. Если понадобится ещё один администратор:
пусть напишет боту `/id`, номер добавьте в `ADMIN_TELEGRAM_ID` через запятую.

## 8. Проверка

```bash
node tools/check-deploy.mjs https://ваш-адрес.vercel.app
```

Скрипт проверит: приложение отвечает, база подключена (`store: pg`), хранилище файлов
подключено (`media: blob`), токен и администратор заданы, каталог отдаётся, admin API закрыт
без подписи Telegram, вебхук на месте.

Руками стоит пройти то же самое в Telegram:

1. Бот → `/start` → кнопка **Каталог** → открывается приложение с заставкой.
2. Абдуллах → `/admin` (или кнопка «⚙️ Админ-панель») → открывается панель.
   У любого другого человека там «Доступ только для администратора».
3. В панели измените любой текст → у клиента он появится в течение 30 секунд.
4. Добавьте квартиру с фото → фото уходит в Blob, карточка видна всем.
5. Перешлите боту пост из канала → создаётся черновик с фото.

```bash
git add . && git commit -m "правки" && git push
```

## Что стоит знать

* **Видео из панели — до 4 МБ.** Vercel не принимает запросы больше 4,5 МБ. Панель об этом
  предупредит и предложит отправить видео боту в Telegram: бот принимает до 20 МБ и сам
  добавляет видео в карточку. Фото ограничение не касается — приложение ужимает их в браузере.
* **Видео не сжимается.** На Vercel нет ffmpeg. Снимайте короткие ролики (15–30 секунд);
  обложку для видео приложение делает само в браузере.
* **Тариф.** Бесплатный Hobby у Vercel разрешён только для некоммерческого использования.
  Для бизнеса нужен Pro (20 $ в месяц). Neon и Blob на бесплатных тарифах для этих объёмов
  проходят спокойно.
* **Где смотреть ошибки:** Vercel → проект → Logs. Там видно каждый запрос и сообщения бота.
* **Запуск у себя** (без Vercel, данные в JSON-файлах) по-прежнему работает:
  `npm run dev` → http://localhost:8443/admin?admin. Подробнее — [ЗАПУСК.md](ЗАПУСК.md).
* **Проверки:** `npm test` — 61 проверка: защита админки на своём сервере и полный прогон
  режима Vercel (Postgres, Blob, вебхук, альбомы, заявки, CORS).
