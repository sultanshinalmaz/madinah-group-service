# Madinah Group — Telegram Mini App: жильё, визы, туры и авто в Медине

Мини-приложение Абдуллаха для канала [@madinah_rent](https://t.me/madinah_rent).
Пять вкладок: **Квартиры · Виза · Туры · Авто · Условия**.

* **Квартиры** — каталог с фото, видеообходами и картой, статусы «свободна / забронирована /
  занята», заявка с составом жильцов, условия брони без сюрпризов.
* **Виза** — 15 видов в четырёх группах: поездка (туристическая, умра, транзитная, хадж),
  по приглашению (гостевая, деловая), работа и учёба (рабочая, студенческая, семейная)
  и **икама** (оформление, продление, перевод кафиля, выезд-возврат, окончательный выезд,
  семья в икаму). Заявка приходит готовой: ФИО как в паспорте, вид визы, дата поездки,
  «Цена: уточняйте» — цены плавающие. Уходит визовой компании с пометкой «клиент от
  Абдуллаха», копия — Абдуллаху.
* **Туры** — зиярат по Медине с Абдуллахом-гидом (маршрут: Ухуд, Куба, аль-Киблатайн,
  сад Салмана аль-Фариси, финиковая ферма) и умра-тур под ключ.
* **Авто** — Lincoln MKX 2016 и Lincoln MKX 2013 (full option), обе чёрные. У каждой машины
  статус «Свободна / Забронирована до …»; клиент выбирает даты и срок (сутки, 3 дня, неделя,
  месяц), видит, свободна ли машина, и стоимость. На занятые даты заявку не отправить.
  Пока нет фото — в карточке рисунок машины в её цвете.
* **Режим работы — круглосуточно:** в контактах, в заявках и в приветствии бота.
* **Условия** — отдельно по каждой услуге, плюс «кто сдаёт» и контакты.

У риелтора есть **панель**: квартиры, фото и видео, статусы, цены услуг, машины,
закрытый **отчёт** (заработок, сдано квартир, возвраты) и **PDF-политика для владельцев**.
Три языка: русский, узбекский, английский (RU · UZ · EN в шапке).

Фронтенд без сборки: обычные HTML, CSS и JS. Backend — одна функция Vercel (`api/[...path].js`),
данные в Postgres, фото и видео в Vercel Blob, бот на вебхуке.
На своём компьютере то же самое работает обычным сервером и JSON-файлами.

## Как это устроено

| Слой | На Vercel | У себя на компьютере |
|---|---|---|
| приложение (index.html, assets/) | статика на CDN Vercel | раздаёт `bot/server.js` |
| API, админка, бот | функция `api/[...path].js` | тот же `bot/server.js` |
| общая логика | `lib/app.js` | `lib/app.js` |
| данные | Postgres (`DATABASE_URL`), таблица `docs` | JSON-файлы в `bot/data/` |
| фото и видео | Vercel Blob (`BLOB_READ_WRITE_TOKEN`) | `bot/data/media/` + ffmpeg |
| бот | вебхук `APP_URL + api/webhook` (ставится сам) | опрос Telegram |

Выбор делается сам: есть `DATABASE_URL` — работаем с Postgres, нет — с файлами; есть
`BLOB_READ_WRITE_TOKEN` — файлы в облако, нет — на диск. Один и тот же код, ничего переключать не нужно.

## Установка и запуск

Нужно: **Node.js 20 или новее** (`node -v`). Для запуска у себя ffmpeg не обязателен
(с ним видео сжимается).

```bash
npm install
cp .env.example bot/.env      # вписать BOT_TOKEN
npm run dev                   # http://localhost:8443/admin?admin
```

Три главные переменные (полный список — в [.env.example](.env.example)):

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_TELEGRAM_ID` | числовой Telegram ID администратора (@RakhimovAbdullah) — `593048264` |
| `APP_URL` | адрес приложения с `/` на конце, например `https://madinah-group.vercel.app/` |

Секреты лежат только в переменных окружения (на Vercel — Settings → Environment Variables,
у себя — `bot/.env`, он в `.gitignore`); во фронтенд они не попадают.
Как выложить на Vercel — [ДЕПЛОЙ.md](ДЕПЛОЙ.md).

### Настройка бота в Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` → имя `Madinah Group`, username вроде
   `MadinahGroupBot`. BotFather пришлёт токен — впишите его в `BOT_TOKEN`.
2. `/setmenubutton` → ваш бот → адрес `APP_URL` → название `Каталог`. Это кнопка Mini App у всех.
3. По желанию `/newapp` → ссылка вида `https://t.me/MadinahGroupBot/catalog` для канала.
4. Mini App открывается только по **https** — без домена и сертификата Telegram его не покажет.

### Как узнать Telegram ID и настроить ADMIN_TELEGRAM_ID

Доступ к админке даётся **только по числовому ID**, не по username: username можно сменить
или передать другому, ID — нет.

1. Запустите сервер с `BOT_TOKEN` (ADMIN_TELEGRAM_ID пока пустой).
2. Абдуллах пишет боту **`/id`** — бот отвечает: `Ваш Telegram ID: 123456789`.
   Другой способ — написать [@userinfobot](https://t.me/userinfobot).
3. Впишите число в переменную `ADMIN_TELEGRAM_ID` (на Vercel — Settings → Environment Variables,
   затем Redeploy; у себя — `bot/.env` и перезапуск). Несколько администраторов — через запятую.
   Если впишете `@RakhimovAbdullah`, сервер предупредит, что это не число, и админку не откроет.
   Telegram ID Абдуллаха уже известен: **593048264**.

### Админ-панель `/admin`

Открывается изнутри Telegram: бот → `/admin` или кнопка **«⚙️ Админ-панель»** после `/start`
(её видит только администратор), либо кнопка «Админ-панель» в полосе риелтора в каталоге.
Любой другой человек на `/admin` увидит «Доступ только для администратора» и свой ID.

Что правится (сохраняется в базе и сразу видно клиентам — открытое приложение
подтягивает изменения само, в течение 30 секунд):

| Раздел | Что внутри |
|---|---|
| Квартиры | добавить, изменить, фото и видео, статус, закрепить наверху |
| Машины | добавить, фото, год, цвет, комплектация, цена, статус брони |
| Услуги и цены | доля с визы, какие визы показывать, цены туров, маршрут зиярата |
| Тексты услуг | тексты виз, туров, авто; порядок и видимость видов виз и туров; фото-обложки туров |
| Бренд и контакты | название, подзаголовок, «о себе», ссылка на канал, Telegram, WhatsApp, телефоны, часы |
| Условия и шаги | разделы условий, спорные ситуации, «главное из условий», галочка согласия, шаги сделки |
| Тексты и кнопки | любая надпись приложения на RU / UZ / EN — заголовки, кнопки, подсказки |
| Разделы и порядок | порядок и видимость вкладок, блоки «Карта», «Избранное», «Кто сдаёт», «24/7» и др. |
| Изображения | логотип (шапка и значок) и эмблема заставки — загрузить или вернуть стандартные |
| Районы | названия, описания, расстояние до Харама, координаты |
| Отчёт, визовая компания, PDF для владельца | как и раньше |

### Как защищена админка

* Telegram подписывает `initData` токеном бота. Сервер проверяет подпись (HMAC-SHA256),
  свежесть (не старше суток) и сверяет `user.id` с `ADMIN_TELEGRAM_ID`.
* Так проверяется **каждый** запрос `/api/admin/*` — и чтение, и сохранение, и загрузка файлов.
  Флаг «админ» в браузере, localStorage, DevTools, куки или прямой запрос без подписи ничего
  не открывают (проверено: см. «Проверка»).
* Админские скрипты загружаются только после подтверждения сервером; обычному пользователю
  на `/admin` не отдаются ни данные, ни кнопки.
* Admin API не отвечает чужим сайтам (CORS разрешён только для `APP_URL`).
* Тексты из админки сохраняются без HTML, ссылки проверяются (только `https://`), фото — только
  загруженные через приложение (своя папка или хранилище Blob этого проекта).
* Режим проверки без Telegram (`--dev` и **без** `BOT_TOKEN`) пускает в панель только с этого
  компьютера. Если токен задан, этот обход выключен.

## О чём договорились с Абдуллахом (запись разговора)

* **Роль риелтора:** связывает и заселяет — на этом его работа заканчивается. Конфликты
  с владельцем, поломки и всё после заселения — между жильцом и владельцем.
* **Кто заселяется:** в заявке обязательно — семья, братья или сёстры и сколько человек
  (с детьми). Приехали другие или больше (заявили двоих — приехали восемь) — владелец
  вправе не заселять, сумма брони аннулируется и остаётся владельцу, остальное возвращает
  владелец. Риелтор этих денег себе не берёт.
* **Начало аренды:** с дня, когда оплата передана владельцу, а не с дня приезда
  (оплатили 3-го, приехали 7-го — месяц с 3-го).
* **Заселение:** всё проверяется сразу, замечания — в тот же день с фото.
* **Галочка** «согласен с условиями» — это согласие, даже если текст не прочитан.
* **Форс-мажор:** землетрясения и другие стихийные бедствия, решения властей, задержка
  или отмена рейса, отказ в визе — риелтор не отвечает.
* **Политика для владельцев-арабов** — отдельный PDF на арабском, чтобы прочитали и подписали.
* **Визы** — через визовую компанию: заявка сразу ей, клиент помечен «от Абдуллаха»,
  цена для таких клиентов на 5 % выше (при цене 100 $ — 5 $), эти деньги — доля Абдуллаха.
* **Отчёт** видит только Абдуллах: сколько заработал за месяц, сколько квартир сдал,
  возвраты («оплатил и забрал обратно»).
* **Потом пришлёт:** фото и цены машин, ещё 6–7 мест для зиярата, контакты визовой компании.

## Что умеет

**Клиент**
* Каталог: фото листаются стрелками и свайпом, счётчик «3 / 7», метка «Видеообход».
  Внутри вкладки «Квартиры» — переключатель «Список · Карта · Избранное».
* Карточка: большое фото + лента миниатюр, полноэкранный просмотр, видео в приложении.
* Карта: цена на пинах, скопления районов, кольца 1–3 км вокруг Масджид ан-Набави,
  ориентиры — мечети Куба и аль-Киблатайн.
* Забронированные и занятые квартиры видны с плашкой «Забронирована до 30.09»
  и кнопкой «Встать в очередь». Свободные всегда наверху.
* Заявка на квартиру: кто заселяется и сколько человек (приложение само не пустит
  братьев в квартиру «только для семей» или четверых туда, где можно двоих), дата,
  срок, главное из условий и галочка согласия.
* Заявки на визу, тур и машину — свои формы и свои условия; без сервера заявка
  уходит в WhatsApp готовым текстом.

**Риелтор** (его числовой Telegram ID — в `ADMIN_TELEGRAM_ID`; всё правится на странице `/admin`)
* Квартиры: фото и видео с телефона, текст поста раскладывается по полям сам,
  перевод на узбекский и английский, точка на карте, быстрый статус.
* **Услуги и цены:** доля с визы (5 %), какие виды виз показывать клиентам, цены туров,
  места маршрута. Цены виз клиенту не показываются — «уточняйте».
* **Машины:** «+ Добавить машину» прямо во вкладке «Авто» — фото, марка, год, цвет,
  комплектация, мест, коробка, цена в сутки, залог. В карточке каждой машины — быстрый
  статус «Свободна / Забронирована до …». Когда Абдуллах нажимает «✅ Договорились» под
  заявкой, машина сама становится забронированной на эти даты, клиенту приходит ответ.
* **Визовая компания:** «Отправить ссылку компании» — компания жмёт «Старт» в боте,
  и заявки на визу и по икаме идут ей. Под заявкой у неё кнопки «Оформлено» / «Отказ».
* **Отчёт:** месяц за месяцем — заработано, возвраты, итого (доллары по курсу 3,75),
  сдано квартир, заявки по разделам. Подтверждённые брони и оформленные визы
  попадают туда сами, остальное — «+ Добавить запись».
* **PDF для владельца:** одна кнопка — PDF на арабском приходит в чат с ботом, оттуда
  его пересылают владельцу. Есть русский перевод и английская версия.
* Бот: заявки с кнопками, `/list`, `/book`, `/busy`, `/free`, `/sold`, `/new`,
  `/report` (отчёт за месяц), `/owner` (PDF для владельца), импорт постов канала.

## Где хранятся данные

Одни и те же записи, только в разных местах:

| Запись | Что внутри |
|---|---|
| `listings` | квартиры |
| `districts` | районы |
| `services` | визы, туры, машины, цены |
| `content` | тексты, кнопки, контакты, условия, разделы, логотип — всё из `/admin` |
| `bookings`, `requests` | заявки |
| `deals` | сделки для отчёта |
| `settings` | визовая компания, служебное |
| `rev` | номер правки: по нему приложение подтягивает изменения |

* **На Vercel** — строки таблицы `docs` в Postgres (ключ + JSON). Таблица создаётся сама
  при первом запросе. Новый деплой данные не трогает.
* **У себя** — те же записи файлами в `bot/data/` (`listings.json` и так далее),
  фото и видео — в `bot/data/media/`. **Эту папку сохраняйте в резервные копии.**

При первом запуске квартиры, районы и услуги копируются из `assets/js/data.js`,
дальше их правят из панели.

Приложение само понимает, открыто ли оно со своего сервера (`booking.api: 'auto'`).

## Про фото и видео

Медиа взяты из постов канала как есть: в посте фото — в карточке все фото; фото и видео —
и то и другое; только видео — карточка открывается видеообходом, кадры не нарезаются.
Фото из веб-версии Telegram (до 800 px) увеличены нейросетью Real-ESRGAN (General x4v3,
Qualcomm AI Hub, BSD-3): края и текстуры чёткие, мебель и планировка не менялись.
Самое чёткое — оригиналы: если переслать боту пост, он заберёт фото в полном размере.

## Политика для владельцев (PDF)

Текст — в `tools/owner-policy.html` (арабский, русский, английский). После правки:

```bash
node tools/owner-pdf.mjs
```

Арабский текст составлен по договорённостям из записи. Перед тем как давать владельцам
на подпись, пусть его прочитает человек, для которого арабский родной.

## Проверка на своём компьютере

```bash
node bot/server.js --dev
```

Открыть http://localhost:8443/admin?admin — админ-панель, http://localhost:8443/?admin — каталог
глазами риелтора, без `?admin` — вид клиента. Это работает только с этого компьютера и только
без `BOT_TOKEN`. Бот в этом режиме выключен: его сообщения печатаются в окне сервера,
риелтор — «чат 1». Только каталог, без сервера: `node dev-server.js` → http://localhost:5180.

### Проверки

```bash
npm test                                             # 61 проверка
node tools/check-deploy.mjs https://ваш-адрес.vercel.app   # уже развёрнутое приложение
```

  пользователь, администратор, подменённый id, подпись другого бота, просроченная и «будущая»
  подпись, `X-Dev-Admin`, куки «я админ», прямые запросы к `/api/admin/*`, загрузка файла,
  CORS, HTML в надписях, `javascript:`-ссылки — **32 из 32**;
* `tools/test-vercel.cjs` — режим Vercel целиком (Postgres в памяти, эмуляторы Blob и Telegram):
  данные пишутся в базу и переживают новый деплой, фото уходят в Blob, слишком большой файл
  отклоняется с подсказкой, чужая ссылка на фото отбрасывается, вебхук с чужим секретом — 403,
  пересланный пост становится черновиком, второе фото альбома дописывается в ту же карточку
  (другим экземпляром функции), заявки уходят риелтору, вебхук прописывается сам — **29 из 29**;

  и скриптов, `/admin` — «нет доступа»; администратор правит подзаголовок, надписи, вкладки,
  условия — у открытого приложения пользователя правка появляется без перезагрузки — **11 из 11**.
