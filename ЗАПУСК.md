# Запуск Madinah Group — по шагам

Приложение, панель риелтора и бот работают от одного Node-сервера (`bot/server.js`).
Без сервера каталог тоже открывается (например, с Netlify), но тогда Абдуллах не сможет
сам добавлять квартиры и менять статусы — для этого и нужен сервер.

| Этап | Время | Что получаем |
|---|---|---|
| 1. Проверить на своём компьютере | 5 минут | всё работает локально, панель риелтора открыта |
| 2. Бот в @BotFather | 5 минут | токен бота и ссылка на каталог |
| 3. Сервер (VPS) | 30–40 минут | приложение по https, панель, заявки в личку, импорт постов |
| 4. Передать Абдуллаху | 10 минут | он сам ведёт каталог — см. `ИНСТРУКЦИЯ-РИЕЛТОРУ.md` |

---

## Этап 1. Проверить на своём компьютере

```
node bot/server.js --dev
```

Откройте **http://localhost:8443/admin?admin** — это админ-панель: тексты, кнопки, контакты,
условия, разделы, квартиры, машины, отчёт. **http://localhost:8443/?admin** — каталог глазами
риелтора (полоса «Панель риелтора», быстрый статус в карточках). Без `?admin` — вид клиента.

В режиме `--dev` бот выключен, заявки печатаются в окне сервера. Панель без Telegram
открывается только с этого компьютера — снаружи режим проверки не пускает.

---

## Этап 2. Бот в @BotFather

1. `/newbot` → имя `Madinah Group — жильё, визы, туры в Медине`, юзернейм вроде `MadinahGroupBot`.
   BotFather пришлёт **токен** — никому его не показывайте.
2. Telegram ID Абдуллаха — это **число**, не @username. Когда сервер запущен с токеном, пусть
   напишет вашему боту `/id` — бот ответит номером. Или [@userinfobot](https://t.me/userinfobot).

Кнопку меню и ссылку для канала настроим на этапе 3, когда будет https-адрес.

## Этап 3. Сервер

> **Основной способ — Vercel:** GitHub → Vercel → база и хранилище файлов подключаются
> кнопкой, адрес с https выдаётся сразу, вебхук бота ставится сам.
> Пошагово — в [ДЕПЛОЙ.md](ДЕПЛОЙ.md). Ниже — вариант со своим сервером (данные в файлах).

Подойдёт самый дешёвый VPS на Ubuntu (Timeweb, Aeza, Hetzner — от 4–5 $ в месяц).

1. **Бесплатный домен.** На https://www.duckdns.org войдите через Google, создайте имя
   `madinah-group` и впишите IP сервера. Адрес: `madinah-group.duckdns.org`.

2. **Программы на сервере:**

   ```
   apt update && apt install -y nodejs ffmpeg caddy
   ```

   `ffmpeg` сжимает видео, которые Абдуллах загружает с телефона, и готовит фото из
   пересланных постов. Node нужен версии 18 или новее: `node -v`.

3. **Залить проект** в `/opt/madinah-rent` (FileZilla, WinSCP или `scp -r`).
   Папку `bot/data` с компьютера **не заливайте** — сервер создаст её сам и возьмёт
   стартовый каталог из `assets/js/data.js`.

4. **Настройки:** `cp bot/.env.example bot/.env` и заполните:

   ```
   BOT_TOKEN=токен из этапа 2
   ADMIN_TELEGRAM_ID=числовой id Абдуллаха
   APP_URL=https://madinah-group.duckdns.org/
   ```

5. **Приложение как служба** — поднимется само после перезагрузки:

   ```
   cp deploy/madinah-bot.service /etc/systemd/system/
   chown -R www-data /opt/madinah-rent
   systemctl daemon-reload && systemctl enable --now madinah-bot
   ```

6. **https.** В `deploy/Caddyfile` поставьте свой домен, затем:

   ```
   cp deploy/Caddyfile /etc/caddy/Caddyfile && systemctl reload caddy
   ```

   Через минуту открывается `https://madinah-group.duckdns.org` — это и есть приложение.

7. **Кнопки в Telegram** (в @BotFather):
   * `/setmenubutton` → бот → адрес приложения → название `Каталог`;
   * `/newapp` → бот → название `Madinah Group`, описание
     `Жильё, визы, туры и авто в Медине · Madinada uy-joy, viza, tur va avto · Homes, visas, tours & cars in Madinah`,
     фото `deploy/cover-640x360.png`, адрес приложения, короткое имя `catalog`.
     Получится ссылка **`https://t.me/MadinahGroupBot/catalog`**.

8. **Закрепить в канале** пост с картинкой `deploy/cover-1280x720.png`:

   > 🏠 Madinah Group — всё для поездки в Медину в одном приложении
   > Свободные квартиры с ценами и картой · визы (туристическая и для умры) ·
   > зиярат по Медине с гидом · аренда машин. Заявка в два касания.
   > 👉 https://t.me/MadinahGroupBot/catalog
   >
   > 🏠 Madinah Group — Madina safari uchun hammasi bitta ilovada
   > Narxi va xaritasi bilan bo‘sh kvartiralar · viza (turistik va umra) ·
   > Madina bo‘ylab gid bilan ziyorat · avtomobil ijarasi. Ikki bosishda ariza.
   > 👉 https://t.me/MadinahGroupBot/catalog
   >
   > 🏠 Madinah Group — everything for your Madinah trip in one app
   > Available apartments with prices and a map · visas (tourist and umrah) ·
   > guided ziyarat of Madinah · car rental. Request in two taps.
   > 👉 https://t.me/MadinahGroupBot/catalog

Проверка: Абдуллах пишет боту `/start` — под приветствием кнопка **«⚙️ Админ-панель»**
(или команда `/admin`). В каталоге у него вверху «Панель риелтора». У остальных этого нет,
а на `…/admin` они видят «Доступ только для администратора».

9. **Визовая компания:** Абдуллах во вкладке «Виза» нажимает «Отправить ссылку компании»
   и пересылает её компании. Компания жмёт «Старт» — заявки на визу пойдут ей.

## Этап 4. Передать Абдуллаху

Отправьте ему файл `ИНСТРУКЦИЯ-РИЕЛТОРУ.md` (там по-русски и по-узбекски).
Главное, что он должен знать:

* **Новая квартира** — «Панель риелтора» → «Добавить квартиру»: фото и видео прямо
  из галереи телефона, текст из поста канала вставляется и раскладывается по полям сам,
  точка ставится на карте касанием. После «Сохранить и показать» квартира сразу видна
  в каталоге и на карте.
* **Или переслать пост из канала боту** — фото подтянутся в полном качестве,
  а бот пришлёт черновик на проверку.
* **Статус** — в карточке квартиры: Свободна / Забронирована / Занята / Сдана / Черновик.
* **Заявки** приходят в личку с кнопками «✅ Забронировать» и «✖ Отказать» —
  одно нажатие меняет статус в приложении и отвечает клиенту.
* **Услуги** — «Панель риелтора» → «Услуги»: цены виз (наценка считается сама), туры,
  места маршрута, машины с фото.
* **Отчёт** — «Панель риелтора» → «Отчёт» или `/report` в боте. Видит только он.
* **PDF для владельца** — «Панель риелтора» → «PDF для владельца» или `/owner` в боте.

## Если нужен каталог без сервера (быстрая демонстрация)

`node tools/pack.js` → папку `dist/site` перетащить на https://app.netlify.com/drop.
Каталог, карта, фильтры и условия работают, заявки уходят в WhatsApp готовым текстом.
Панель риелтора и загрузка фото в таком варианте недоступны.

## Обслуживание

| Что | Как |
|---|---|
| Перезапустить | `systemctl restart madinah-bot` |
| Посмотреть, что пишет сервер | `journalctl -u madinah-bot -n 50` |
| Резервная копия квартир, фото, услуг и отчёта | скопировать папку `/opt/madinah-rent/bot/data` |
| Поправить текст политики для владельцев | `tools/owner-policy.html`, затем `node tools/owner-pdf.mjs` на компьютере и залить `assets/docs` |
| Обновить код приложения | залить новые файлы поверх, кроме `bot/data` и `bot/.env`, затем перезапустить |
| Начать каталог заново из `data.js` | `node bot/server.js --reseed` (текущие квартиры в панели будут заменены!) |
